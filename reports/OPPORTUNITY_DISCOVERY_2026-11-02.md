# Proactive Opportunity Discovery — First Portfolio Scan

**Observation date:** 2026-11-02  
**Status:** FIRST-PASS / EVIDENCE-BOUNDED  
**Scope:** A targeted review of four current software-project repositories plus official program pages. This is not a full audit of all portfolio repositories, and it does not establish personal or company eligibility.

## Executive decision

1. **Best immediate local route to prepare:** Startup.dz **Label projet innovant**. The official portal explicitly distinguishes project holders who have not yet created a company from companies applying for the Startup label. The project-label form requests founder information, a pitch deck, a detailed innovation description, a prototype image, development stage, business model, website, and incubator details.
2. **Downstream local funding path:** the Startup label is for an already registered company. The Algerian Startup Fund (ASF) states that the label is a prerequisite for its investment route. ASF describes equity and quasi-equity instruments; this must not be represented as a grant or guaranteed financing.
3. **International cloud credits:** worth preparing for, but eligibility is currently **UNKNOWN**. The public programs require company/startup facts not established in this scan: legal entity, company website/domain, age, funding, accelerator affiliation, prior credits, and sometimes regional service eligibility.
4. **OpenAI sharing incentives:** a real program, but the screenshot previously discussed was explicitly not the user's account. No eligibility or enrollment is established for the user. Do not enable sharing until the eligible organization, data scope, privacy permissions, and realized savings are verified.

## Project fit: inspected repository evidence

Inspection was limited to the default-branch README plus the latest commit returned by the connected GitHub search surface. This is **D1/documentation evidence**, not a code or runtime audit.

### Medad

- Repository/ref: `Loofy147/Medad`, `main`, commit `bed7ec743bc29a33f5562e2b0c7f59f5b019701b`.
- **OBSERVED:** README describes an Arabic-first commerce-partnership workspace, an interactive local prototype, and a deterministic Python unit-economics engine.
- **OBSERVED:** the same README says live market, supplier, courier, advertising, order, partner, and AI integrations are not connected; sample product ideas and values are illustrative.
- **INFERENCE:** strongest of the inspected candidates for a product-specific innovation dossier because there is a coherent workflow and a deterministic economics core. It still needs real-world data, a user/pilot, and evidence that the workflow improves a measurable business decision. Do not claim demand or commercial readiness yet.

### Taskora

- Repository/ref: `Loofy147/Taskora`, `main`, commit `45811a8cb15cc26eceb1de76e992013be82f0252`.
- **OBSERVED:** README describes a task/project/team prototype and an opt-in personal workspace snapshot bridge.
- **OBSERVED:** README explicitly says authentication and durable PostgreSQL are disabled in the shipped environment; individual server-side task CRUD, real team sharing/invitations, binary file storage, and operational notifications are not enabled or verified.
- **INFERENCE:** infrastructure credits may become useful once the production backend requirements are real. Do not migrate hosting solely to consume credits; finish the intended architecture and compare actual cost/lock-in first.

### Dz-luncher

- Repository/ref: `Loofy147/Dz-luncher`, `main`, commit `443fb5e4b73acb9c843510d14bf1f2376e16347a`.
- **OBSERVED:** README describes an Arabic-first Algerian survey and market-validation platform and states that the repository is an initial bootstrap.
- **INFERENCE:** not yet ready for an application claiming a working product. The survey/validation engine and respondent/reward workflow need an evidenced end-to-end prototype and at least one real pilot.

### Unified Knowledge Work System

## Application-readiness interpretation

**Provisional first dossier candidate: Medad.** This is a work-priority hypothesis, not a claim that Medad is already eligible, accepted, or commercially validated. Its prototype and deterministic economics engine provide a more tangible starting point than a bootstrap-only repository; the decisive missing evidence is a real data-backed workflow and a pilot.

Before presenting Medad (or another project) as innovative, establish:
- one sharply bounded customer and costly decision;
- the end-to-end workflow and measurable before/after value;
- provenance and freshness of any market/supplier/delivery/advertising data;
- reproducible unit economics, including returns and failure scenarios;
- at least one real pilot or documented customer validation;
- product ownership, founding team, incubation, and legal status evidence.
