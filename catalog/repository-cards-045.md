## Rule

A repository is "covered" only at the level actually supported by evidence:

- ENUMERATED: present in the 2026-08-30 census.
- STRUCTURAL: root/tree inspected.
- IDENTIFIED: purpose can be stated from README/source evidence.
- LINEAGE-CANDIDATE: relationship suspected but not proven.
- PROVENANCE-SENSITIVE: upstream/template/derived origin detected.
- UNRESOLVED: insufficient evidence for reliable semantic identity.

No repository is upgraded to IDENTIFIED merely because its name is suggestive.
