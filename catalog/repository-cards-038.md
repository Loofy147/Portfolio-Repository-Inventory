## Coverage note

This batch confirms that GitHub search paging is not a clean authoritative census mechanism: search pages return overlapping/re-ranked results. The inventory should therefore maintain two separate measures:

1. **Enumerated owner-visible repositories**: repositories observed through owner-scoped GitHub enumeration/search.
2. **Inspected repositories**: repositories for which actual README/tree/source evidence has been inspected.

A repository appearing in the first set must not be counted as semantically understood until it enters the second set.
